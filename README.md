# 🎨 1magen - AI Image Generation App

**An intuitive AI-powered image generation platform leveraging modern web technologies**

1magen is a state-of-the-art web application designed to transform text prompts into stunning visuals. With a robust toolset of features, including multiple AI models and comprehensive customization options, it offers a seamless experience for users looking to create, store, and manipulate generated images directly from their browser.

## ✨ Features

### 🔧 **Core Functionality**
- **AI Image Generation** - Transform text prompts into images using advanced AI models
- **Multiple Models** - Choose from models like `Flux`, `GPT-Image`, and `Turbo`
- **Customizable Dimensions** - Fine-tune image resolution with presets like Square, Portrait, or HD
- **Batch Processing** - Generate multiple images from a single prompt effortlessly
- **Stylistic Presets** - Apply styles such as 'Photorealistic', 'Cinematic', or 'Pixel Art'
- **Prompt Assistance** - Enhance creativity with keyword and style suggestions

### 📊 **Advanced Features**
- **Interactive History** - Save and review all generated images and settings
- **Comparison Mode** - Compare images side-by-side from your history
- **Preset Management** - Save favorite settings and prompt combinations
- **Local Storage** - All images and presets saved directly in browser (no account needed)
- **Dark & Light Mode** - Adapt UI for optimal viewing in any lighting
- **Responsive Design** - Optimized for desktops, tablets, and mobile

## 🚀 Quick Start

### Prerequisites
- **Node.js** 18.x or higher
- **npm** 8.x or higher
- **Git**

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/melvsalonga/1magen-app.git
   cd 1magen-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Access the application**
   Open your browser to `http://localhost:3000`

## 📝 Available Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Start development server with Turbopack |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## 🎨 Usage Examples

### Generate Your First Image
1. Enter a creative prompt (e.g., "A majestic lion in a futuristic city, cinematic lighting")
2. Select your preferred AI model (Flux, GPT-Image, or Turbo)
3. Adjust dimensions or choose from presets
4. Click "Generate" and watch your vision come to life!

### Save & Reuse Settings
- **Save Presets**: Click "Save Preset" to store your favorite prompt and settings
- **Load Presets**: Access saved configurations from the Presets tab
- **History**: Review all generated images in the History tab
